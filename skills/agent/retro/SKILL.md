# 会话复盘

读取 `writing-for-agents`，以指定会话的原始记录为证据；未指定则复盘当前会话。用户需要改善的是下次工作的环境。

1. 找出造成返工或延迟的具体事件：找不到文件、漏读规则、信息不可访问、工具重复调用、规范含混、已有检查未运行。
2. 查看仓库已有构建、分析器和检查入口。区分“已有能力没接通”和“确实缺能力”，不要凭没有 CI 就判定有问题。
3. 每项建议给出事件证据、原因、最小改进、作用位置及代价。可机械判断的错误优先考虑已有编译器/分析器；需要判断力的要求进入审查规范；AGENTS 保留简短导航。
4. 按影响排序呈现候选，等用户选择再实施。调用本 skill 只授权分析和建议，不自动新增测试、CI、hooks，或修改全局规则。

遵守 C# 工作流的手动验收边界。用户明确要求自动化测试时才新增测试。资料或设备不可访问时说明证据缺口，不把推测写成会话事实。
