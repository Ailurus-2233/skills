写给 agent 消费的任何文档的参考：skill、`AGENTS.md`、被指针触达的文档。包装不同，写法相同：同一组杠杆让每份文档可预测，因为 agent 每次运行走的是同一个**过程**，而不是产出同一个结果。

## 上下文指针

**上下文指针**是 agent 上下文里的一行引用，指名某份不在上下文中的材料，并编码触达它的条件。skill 的 description 是一个；`AGENTS.md` 里指名某文档的一行也是。决定 agent 何时触达材料的是指针的**措辞**，不是目标。必须读的目标藏在措辞软弱的指针后面是 variance bug：先磨尖措辞，磨尖无效才内联。

指针做两件事：说明材料是什么，列出应触发触达的**分支**。始终加载的指针每个词每轮都在付费，比正文更值得修剪：

- **前载引导词**：指针在开头做触发工作。
- **一个分支一个触发词**。同义词只是把一个分支写两遍；只保留真正不同的分支。
- **删掉正文已自带的信息。**

## 两种负载

每加一份文档或指针，花费两种预算之一：

- **上下文负载**：始终加载的材料对 agent 窗口的成本（`AGENTS.md` 的一行、skill 的 description）——不管是否触发都在花 token 和注意力。
- **认知负载**：对人的成本——有哪些文档、何时用哪份。人是索引。这不是要最小化的成本，而是人类能动性的价格：花在人的判断力重要的地方，从不重要的地方撤走。

## 信息层级

文档由两类内容构成：**步骤**（agent 按序执行的动作）和**参考**（按需查阅的定义、规则、事实）。核心决策是每块内容坐在**信息层级**的哪一级——按 agent 需要它的即时程度排序：

1. **文件内步骤**：主层级，agent 按序做的事。
2. **文件内参考**：按需查阅。扁平的同侪集合（评审的所有规则坐同一级）是正常的，不是坏味道。
3. **披露式参考**：推到独立文件里，由上下文指针触达，指针触发才加载。

**渐进披露**就是往梯子下层挪，让顶层保持可读。最干净的披露测试是分支：每个分支都需要的内联，只有部分分支触达的推到指针后面。**同位**是文件内的伴侣：一个概念的定义、规则、注意事项收在同一个标题下，读一部分就把邻居带出来。**蔓延**是这里的失败模式：文档单纯地太长——解药是梯子：把参考披露到指针后，按分支或顺序切分。

## 步骤与完成标准

每个步骤以**完成标准**收尾。两个属性使它成为杠杆：

- **清晰性**：agent 能否分辨完成与未完成？模糊的边界（"理解达成"）诱发**提前完成**。防御顺序：先**磨尖边界**（局部且便宜）；只有边界本质模糊**且**观察到了赶工，才靠拆分序列把后续步骤藏起来。
- **要求度**："每个改动的模型都有交代"逼出彻底的工作，"产出变更清单"不会。要求度驱动**跑腿量**，且不限于步骤：扁平参考同样能被"每条规则都应用"绑定。

最强的完成标准既可检查又穷尽。

## 何时拆分

拆分花费两种负载之一，只在值得时切：

- **按顺序切**：后续步骤诱惑 agent 赶工当前步骤时切开。警惕反向：合并序列会把每步暴露给后文的诱惑。
- **按调用切**（skill 特有）：一个 skill 是独立被调用的单元时，拆成独立 SKILL.md。

## 引导词

**引导词**是已经活在模型预训练里的紧凑概念（_lesson_、_fog of war_、_tracer bullet_），agent 运行文档时用它思考。作为 token 重复、永不展开成句子，它用最少的 token 锚定一整片行为区域。自造词不招募任何先验：现成词免费给的，你要花定义 token 去买；先找现成的词。

它在正文里锚定**执行**，在指针里锚定**调用**：同一个词住在你的提示、文档、代码库里时，agent 把这份共享语言和材料联系起来，触达更可靠。

**否定**是这个杠杆旁边的失败模式：用禁止来引导会把被禁止的行为拖进上下文，让它更可用。提示**正面**：写出目标行为（"注释只写一行"），让被禁行为从不被说出。禁止只在无法正面表达的硬护栏处保留，且要配上正面目标。

## 修剪

- 每个含义保持**单一事实来源**：一个权威位置，改行为只改一处。**重复**（同一含义出现在多处）花费维护和 token。
- **环境**也是事实来源（配置文件、目录布局、`--help` 输出）；复述环境的文档是**缓存**——只缓存 agent 看一眼找不到的东西：未成文的约定、选择背后的理由、没有配置会坦白的坑。
- 逐行检查**相关性**：这行还与文档的职责有关吗？没有修剪纪律，默认命运是**沉积**。
- 逐句猎杀**无操作句**：模型默认就遵守的指令纯花负载。测试是"它相对默认行为改变了什么？"，过不了就整句删除。
