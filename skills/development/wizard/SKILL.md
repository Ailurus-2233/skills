# Wizard（向导）

**向导**是一个 PowerShell 脚本，带着人逐步走完一套手工流程——这种流程自己动手做很繁琐，每次向 AI 重新解释一遍也很繁琐。它会清屏后逐个阶段展开：说明这一步要做什么、引导人完成操作、采集产生的值、在合适的地方落盘（`.env` 或项目配置文件）、每个阶段都有确认闸门，并显示还剩几个阶段。工控场景的典型用途：安装厂商运行时/授权、配置串口或现场总线驱动、在 PLC 编程软件（如 TIA Portal、CX-Programmer、Studio 5000）里下载程序、现场接线与上电确认；也包括一次性迁移、把项目从一种状态切到另一种状态。

本 skill 不提供模板文件。下面约定脚本结构，每个向导都照这个结构写；结构的一致性本身就是目的：不要随手另搞一套。

## 脚本结构约定

脚本分两个区：**库函数区**在上，**STAGES 区**在下。库函数区在每个向导里保持一致，绝不手工改动其中的实现。

库函数区提供以下辅助函数：

- `Stage <标题>`：开始一个阶段。清屏、显示阶段标题和进度（"第 N 步 / 共 M 步"），让屏幕上始终只看得见当前这一步——人需要的信息不会被滚走。
- `Say <文本>`：输出说明文字（要做什么、注意什么）。
- `Ask <提示>`：采集一个公开的值并返回。
- `AskSecret <提示>`：采集秘密值（授权码、密码、密钥），输入不回显。
- `Write-Env <键> <值>`：幂等地写入/更新 `.env`（或指定配置文件）中的键值——已存在则原地更新，不存在则追加；重复运行不产生重复行。
- `Confirm <问题>`：确认闸门。任何不可逆操作（下载程序到 PLC、删除旧配置、切换产线状态）之前必须先 `Confirm`。

STAGES 区按依赖顺序逐个定义阶段，每个阶段是一个函数，只干一件聚焦的事；脚本顶部设 `$TOTAL_STAGES` 为阶段总数，供进度显示使用。结尾输出汇总：哪些值被采集、写到了哪里、哪些阶段是纯动作、下一步该做什么。

## 流程

### 1. 界定流程范围（scope）

弄清人必须亲手做的每一步，以及沿途要采集的每个值。先读仓库，不要开口问冷问题：

- 安装/配置类：`.env`、`.env.example`、`README`、项目配置文件（`.config`、`.json`、`appsettings*.json`）、已有的安装/部署文档——每一个配置项引用都是向导必须产出的值。
- 迁移/切换类：当前状态、目标状态、两者之间不可逆的动作。

然后把排好序的阶段清单和每个阶段产出的值给用户看并确认：用户可以增加、删除、调整顺序。

**完成标准：** 每个阶段按序命名；对每个要采集的值都知道：(a) 人从哪里得到它，(b) 写到哪里（`.env`、配置文件、都不写——有些阶段是纯动作），(c) 是秘密值（`AskSecret`）还是公开值（`Ask`）。

### 2. 映射每个阶段的人行路径

为每个阶段写出人要走的精确路径：打开什么软件或界面、点哪里、值显示在哪个位置、填进哪个变量。例如："安装厂商运行时 → 以管理员运行 setup.exe → 许可证管理器 → 输入授权码 → 确认服务已启动"。**如果你并不确切知道当前的界面或命令，就明说，然后问用户或查官方文档：绝不臆造可能不存在的步骤。**

**完成标准：** 每个阶段都能还原成一段陌生人照做就能完成的说明。

### 3. 编写向导

按上面的结构约定写脚本：库函数区 + STAGES 区，一个阶段一个函数，按依赖顺序排列。守住标准：先指引人到达取值的位置再 `Ask`；秘密值一律 `AskSecret`；每个要持久化的值都 `Write-Env`；任何不可逆动作之前先 `Confirm`；每个阶段都通过 `Stage` 清屏，只保留当前步骤可见。库函数区不要动。

### 4. 静态检查并交付

- 语法检查：`powershell -NoProfile -Command "[ScriptBlock]::Create((Get-Content <script> -Raw))"`；如果装有 PSScriptAnalyzer，再跑一遍 `Invoke-ScriptAnalyzer`。
- 不要自己端到端运行：它会启动厂商软件、阻塞等待人的输入。改为静态走查：第 1 步列出的每个值都被采集、并落到了第 1 步说好的位置。
- 告诉用户运行方法（例如 `powershell -ExecutionPolicy Bypass -File <script>`）。

## 生命周期

向导默认是一次性的：为一次运行而写，放在 `.scratch/` 或 `scripts/` 路径下，活干完即删。只有当用户明确要求"可重复的安装路径"时才提交入库——提交时在 README 里链接它，让下一个人跑脚本而不是再问一遍 AI。
